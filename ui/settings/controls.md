# Settings controls

`SettingsPanel` orders preferences by scope: General, Appearance, Reading, then Code. General
contains Your name and Interface language. Reading groups font preset, size, line height, and
text width; code font and color scheme follow together. Labels follow
[the terminology reference](../../docs/terminology.md).

Reading language is a per-document choice among prepared versions, owned by
[the translation menu](../translate/README.md). It is not a Settings or onboarding preference.
